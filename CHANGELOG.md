# Stockroom release notes

## 1.1.0 — First independent GitHub release

An offline Windows inventory ledger with unique SKUs, stock movements, reorder levels and recorded cost valuation. Arabic and English.

- Independent TypeScript application, server, database and dependency lockfile.
- Product-specific navigation and visual design, Arabic/English interface, RTL and light/dark appearance.
- Validated workflow actions, activity history and exports.
- Actual workspace screenshots, usage and architecture documentation, and structured bug/feature forms.
- Automated domain/API/storage checks, browser journeys, accessibility checks and responsive coverage.
- Windows x64 portable package, application icon and native startup verification.

See [verification evidence](docs/VERIFICATION.md) and the [current boundaries](README.md#current-boundaries) before relying on a feature outside the tested scope.
